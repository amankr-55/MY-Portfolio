GeoSentinel 3D Mine Safety Platform

An end-to-end mission-critical IoT & 3D Geological Strata monitoring system built for real-world mine worker protection.

Hardware + 3D Web Dashboard

Real-Time Geological Telemetry & 3D Strata Mapping

GeoSentinel bridges physical IoT sensors (ESP32 microcontrollers monitoring vibration, seismic shifts, and ambient heat) with an interactive Three.js 3D Strata Visualizer and a React 19 dashboard. It enables real-time spatial mine grid analysis, automated disaster alert simulations, and instant PDF hazard reporting.
